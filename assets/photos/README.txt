📸 THƯ MỤC ẢNH
================

Bỏ ảnh kỉ niệm của tụi mình vào đây.

Cách nhanh nhất:
1. Copy ảnh vào thư mục này.
2. Đặt tên đơn giản: 1.jpg, 2.jpg, 3.jpg, ... (hoặc tên gì cũng được).
3. Mở file  assets/js/config.js , tìm mục "photos" và sửa lại tên file + caption
   cho khớp với ảnh của mình.

Mẹo:
- Ảnh dọc (chân dung) hiển thị đẹp nhất (khung ảnh dạng 3:4).
- Nên nén ảnh dưới ~1MB mỗi tấm để web tải nhanh, nàng mở trên điện thoại đỡ lag.
- Muốn thêm/bớt ảnh: cứ thêm/bớt dòng trong mảng "photos" ở config.js.

Nếu tên file chưa khớp, ô ảnh sẽ hiện "📷 Chưa thấy ảnh" — sửa lại tên là hiện ngay.
